## ✨ Key Features

- **🛫 60fps Sky-to-Runway Airplane Landing Animation (`src/components/HeroSkyLanding.jsx`)**:
  - Watch the luxury flagship jet descend from `35,000 FT` through animated sky clouds with wing contrails, perspective runway approach lights, and realistic tire-smoke touchdown puffs.
  - Interactive **Live Flight Telemetry HUD** (`ALT`, `SPD`, `RWY 09L / VIP`) with one-tap **"Replay Sky Landing"** and **"Takeoff & Land"** controls.
- **📸 Interactive In-App Screen Slider (`src/components/ScreenGallerySlider.jsx`)**:
  - Built-in auto-sliding screen tour with manual `←` / `→` controls, pagination dots, and horizontal thumbnail strip.
- **🎟️ Live API Flight Ticket Booking & Rate Calculator (`src/components/FlightBookingSection.jsx`)**:
  - **Free Live Currency Exchange Rate API** (`https://open.er-api.com/v6/latest/USD`): Converts ticket prices in real time across `USD ($)`, `INR (₹)`, `EUR (€)`, `GBP (£)`, and `AED (د.إ)`.
  - **Free Global Airport/City Geocoding API** (`https://geocoding-api.open-meteo.com/v1/search`): Search any departure or arrival city worldwide with instant autocomplete and in-memory caching.
  - **Free Live Aviation Destination Weather API** (`https://api.open-meteo.com/v1/forecast`): Displays live temperature, wind speed, and flying conditions at the destination airport.
  - **Dynamic Haversine Distance & Multi-Tier Ticket Pricing**: Calculates exact great-circle distance (`km`) and flight duration across 4 bookable tiers (*Executive Seat Share*, *Light Business Charter*, *Super Midsize Luxury Jet*, *Ultra-Long Range Flagship*) with promo code support (`JETLY20` for 20% off).
  - **Interactive Boarding Pass & E-Ticket**: Animated flight takeoff-and-landing confirmation modal that generates a shareable VIP Boarding Pass (`Share.share`) and saves tickets to **My Tickets** (`AsyncStorage` + `localStorage`).
- **📱 Native 5-Tab Navigation & Phone Simulator Toggle**:
  - Switch between **Sky Hub**, **Book Jet**, **Charters**, **Services**, and **My Tickets**, and toggle between **Phone View (`430px`)** and **Full Width** on desktop screens.

## 🛠️ Tech Stack

- **Mobile Framework:** React Native `0.76` (Functional Components, Hooks, `Animated`, `StyleSheet`, `Modal`, `Share`)
- **Cross-Platform Runtime:** Expo SDK `52` (New Architecture enabled) + `react-native-web` + Vite `6`
- **Persistence:** `@react-native-async-storage/async-storage`
- **Free Public APIs (No API Key Required):**
  - Open Exchange Rates API (`open.er-api.com`)
  - Open-Meteo Geocoding API (`geocoding-api.open-meteo.com`)
  - Open-Meteo Aviation Weather API (`api.open-meteo.com`)

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/soumitra69/Flight_Booking_App.git
cd Flight_Booking_App

# 2. Install dependencies
npm install --legacy-peer-deps

# 3. Start the lightning-fast development server (Web / Mobile Preview)
npm run dev

# 4. Launch Expo CLI for iOS / Android (Expo Go)
npm run expo

# 5. Build for production
npm run build
```
